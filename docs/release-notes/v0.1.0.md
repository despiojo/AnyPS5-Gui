First release.

- Downloads the AnyPS5 relinker and Windows system libraries from the AnyPS5 releases, verified against the checksums GitHub lists, and switches between versions.
- Converts a dumped, decrypted PS5 game with the relinker and builds the `libs/` and `app0/` layout it needs. Game files are hard-linked when the output is on the same NTFS drive as the dump, and copied otherwise.
- Checks the game folder before converting and explains what is wrong with it.
- Lists converted games and launches them with per-game settings for display, FSR, frame rate, GPU, sound, vibration and language, plus any other environment variable.
- Shows the relinker's and the game's output, and the exact command and variables used.
- English and Spanish, light and dark.

Extract the zip anywhere and run `AnyPS5Gui.exe`. Tried with AnyPS5 v0.1.5 on Windows 11.
